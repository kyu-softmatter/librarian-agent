Custody — what the index says about its own sources

Thirty findings across both repositories. Four are worth more than their severity: two are the simulator's own INDEX.md defects, rediscovered by tool rather than by reading; one is a finding this tool raised that the source repository then fixed; one is a source repository moving underneath the index.

  • error declared_count_mismatch
    bd:knowledge/source/papers/INDEX.md states 40 entries where 42 sibling files exist. The file is headed do not edit by hand. This was v1's exit condition — the defect a human found by reading, found again by tool.
  • error generator_missing
    That same header names docs/tools/wiki_index.py, which is not in the repository — so the file cannot be regenerated and says not to edit it. A generated artefact outliving its generator is the failure this project exists to catch, and it is resolved by looking rather than by importing.
  • ×7 broken_cross_reference
    Seven wikilinks point at entries nobody wrote. A reference to a file that does not exist is the decay mode this repository was built to catch.
  • ×3 gate_not_traceable_to_code
    ms:G2 · ms:G3 · ms:G4 are implemented — by optics.gate.evaluate, as the decision-engine doc says — and named in no Python file, so no code says which gate is which. This check previously reported them as unimplemented, at error severity, and that claim was false: reporting a traceability gap as a missing implementation cost the exit code its meaning.
  • 0 falsifier_missing
    Was one: the entry research-topic holds up as “a challenge that was upheld” carried no falsifier, so the model case was the one entry that could not itself be challenged. The microscope added the section — so this reads zero, and the assertion now pins zero rather than the defect. The loop closed.
  • 0 gate_declared_not_implemented
    No gate carries a threshold in the docs with nothing behind it.
  • ×2 file_produced_nothing
    kb/sessions/2026-09-07.md and kb/sessions/README.md are candidate files that yielded no document — the microscope grew a folder kind the adapter does not cover yet. One integration test fails on exactly this, which is the signal that job exists for: red means a source repository moved, which is information rather than a defect here.

Every figure on this page came out of the commands below, run against a live index built from a shallow clone. Nothing is illustrative and nothing is rounded.

The mixed-script query is not a demo trick. 물 점도 is two characters, which forms no FTS5 token, so it goes to GLOB while viscosity water goes to MATCH — the split BUILD.md §3 measured. It returns the simulator's own lesson that water viscosity moves 2.06 %/K and that T = 300 K was inherited rather than measured.

The single failing test is the kb/sessions/ discovery above. The counts recorded in README.md were measured against ms@196cdf1; the microscope has since moved to fbedef0, so this page and that table do not agree — which is what index_stale is for.
