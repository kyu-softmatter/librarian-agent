# `kb/00-decisions/` — decision log

One decision per file, named `<YYYY-MM-DD>-<slug>.md`. **Chronological, not a
subject** — that is why it carries number 00 rather than sitting beside the
subject folders.

Inherits the shape of MS `kb/decisions/` (20 entries), which is a learning loop
rather than a record: request -> proposed setting and rationale -> what was
actually used, and why if different -> outcome -> what was learned, and which
file was fixed.

**The last section is the one that makes this folder worth keeping.** A decision
that changed no file is not yet a decision.

No `cards/`, no `evidence/` — a decision is not a claim about the world.
